# portfolio-website
A responsive, multi-page personal portfolio website built as a part of the Year 1 Web Programming module. It showcases my academic background, projects, and contact information.

## Live Demo
You can view the live website here: [Lashayah-Walters Portfolio](https://lashayah-walters.github.io/portfolio-website/)

## Built With
- **HTML5** (78.5%) - Structure of the multi-page layout ('index', 'about', 'projects', 'education', 'contact')
- **CSS* (19.6%) - Styling, layout design, and responsive styling
- **JavaScript** (1.9%) - Interactive elements and dynamic behavior

## Repository Structure
- 'index.html' - Homepage / landing view
- 'about,html' - Background and personal interests
- 'projects.html' - Showcase of academic and techincal projects
- 'education.html' Academic history and qualifications
- 'contact.html - Contact page and form
- 'Portfolio Website Development log.pdf' - Full project development documentation
